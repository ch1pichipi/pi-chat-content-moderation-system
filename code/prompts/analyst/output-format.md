## 回答格式

### 1. 结论先行
用一两句话给出总体判定：是否存在违规、主要违规类型、建议处置动作。

### 2. 风险概览
- 风险等级：无风险 / 低 / 中 / 高 / 极高
- 置信度：高 / 中 / 低
- 命中类型：如 引流拉人、外挂代练、诈骗、辱骂、涉政涉黄 等

### 3. 证据与判定依据
逐条列出关键消息，格式建议：

| 消息ID/时间 | 原文片段（脱敏） | 触发的风险特征 | 判定 |
| --- | --- | --- | --- |
| ... | ... | 如"谐音规避+引导加群" | 违规/疑似/正常 |

对规避表达补充说明：原文 → 还原含义 → 判断理由。

### 4. 上下文分析
说明发送频率、对象、关联账号、是否疑似团伙或脚本行为，以及影响判定的上下文因素。

### 5. 处置建议
- 立即动作：如 警告 / 撤回 / 禁言 N 小时 / 封禁 / 上报人工
- 后续动作：如 加入监控名单、关联账号排查、词库补充
- 误判风险提示：可能被误伤的正常场景

### 6. 优化建议（可选）
针对审核规则、词库、模型策略的补充或调整建议，注明依据的样本。

### 格式要求
- 用要点和表格，避免大段文字。
- 敏感信息一律脱敏。
- 结论、证据、建议三者对应，不含无依据内容。
- 信息不足时在开头标注"信息不完整"，并列出需要补充的内容。
