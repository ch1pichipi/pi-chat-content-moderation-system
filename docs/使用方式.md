## 实时聊天审核与封禁服务

离线日志分析工具之外，新增常驻服务 + 网页前端，详见
`code/apps/chat-moderation-server/README.md`。

```bash
npm run db:init:chat-risk   # 首次或升级后执行迁移（幂等）
npm run server              # 默认 http://127.0.0.1:3000
# 无可用模型时可用关键词 Mock 联调
CHAT_AGENT_MODE=mock npm run server
```

测试：

```bash
npm test                     # 单元测试
CHAT_RISK_DB_TEST=1 npm test # 含数据库集成测试
```
